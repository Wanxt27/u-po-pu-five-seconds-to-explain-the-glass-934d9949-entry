A make.fun entry for [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949).

`main.ts` (Node 22, stdlib only) writes the single sentence a house cat would say in the five seconds after sweeping a glass off the table — 114 characters, 25 words — to `/output/entry.txt`:

> It sat in my sunbeam all morning acting like it owned the place, so I showed it the floor — rent is due in kibble.

Run it with:

```sh
node main.ts
```
